# 🎬 CineVerse - Movie Explorer App

CineVerse is a clean and modern Movie Explorer web application built using HTML, CSS, and JavaScript. Users can create an account, log in, search for movies, save favorites, and manage their watchlist with localStorage.

---

## 🚀 Live Demo

🔗 https://cineverse-movie-explorer.netlify.app/

---

## ✨ Features

✅ User Sign Up and Login  
✅ Authentication using localStorage  
✅ Protected routes  
✅ Logout functionality  
✅ Search movies using API  
✅ Dynamic movie rendering  
✅ Add movies to favorites ❤️  
✅ Remove favorites  
✅ Responsive design  
✅ Clean and modern UI

## ⚙️ Setup Instructions

Clone the repository:

```bash
git clone https://github.com/yourusername/cineverse-movie-explorer.git
```

Open project folder:

```bash
cd cineverse-movie-explorer
```

Open with VS Code and run using Live Server.

---

## 🔑 API Setup

This project uses the OMDb API.

Get your API key:

1. Visit https://www.omdbapi.com/apikey.aspx
2. Generate a free API key
3. Open `app.js`
4. Replace:

```js
const API_KEY = "YOUR_API_KEY";
```

with:

```js
const API_KEY = "your_api_key";
```
